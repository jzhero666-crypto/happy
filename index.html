🛡️ 文化完整性守門

台語腔口、戲曲聲腔、北管／南管／客家八音與原住民族樂器屬情境標籤，不會在全庫隨機中無條件亂塞。只有手動選取、核心本身相關，或開啟「臺灣文化聲響」時才會進入變奏；族群專屬樂器也優先保持同一文化脈絡。英文輸出屬自然語言 prompt descriptor／實測別名，不宣稱每一項都是 Suno 官方固定 tag。

💡 這個模式會怎麼做？

核心曲風永遠留在第一順位；驚喜主要分配到 Groove、Vocal、特色樂器、Texture、Production、Regional color 與 META。Balanced 保持可辨識，Wild 允許更多跨界；不以外部指南的 4–7 個描述詞作硬限制。

設定會保存在瀏覽器；生成後可直接按「再變奏一次」連抽不同版本。

📖 ZML Suno Prompt Studio｜快速使用說明

第一次用不用研究全部功能，先照 ①→④ 就能開始。

① 選 Style 標籤
從曲風、人聲、BPM、樂器、情緒、地區文化等分類點選。介面顯示繁中，真正輸出給 Suno 的內容維持英文。
② 沒靈感：全庫隨機抽
一次建立 Style、同源 Lyrics META 與 Smart Exclude。文化情境標籤不會為了輪抽公平而無條件亂塞。
③ 有固定曲風：核心風格變奏
鎖定 R&B、Rock、Mandopop 等，再用 DNA 滑桿決定保留比例。DNA 越高越接近母風格；越低越容易出現跨界曲風與特色樂器。
④ Lyrics META
按「🎼 依 Style 生成 META」，網站會依同一份風格建立編曲 META；META 密度可選 Minimal 1–2 / Balanced 2–4 / Detailed 3–5 / Rich 5–7，並由衝突守門器依段落、Style Profile 與能量曲線選擇。也可使用「自訂歌曲結構」自由排序。
★ 我的收藏 Presets
可替喜歡的整套 Style / Lyrics META / Exclude / DNA 組合命名保存，支援 JSON 匯出／匯入；適合建立自己的常用聲音庫。
🛡️ Smart Exclude
負面提示會從正面 Style 與 META 推導，排除最可能把作品帶歪的元素。它不是越多越好，因此只保留高價值衝突項。若你手動修改 Style，可按「依 Style + META 重建」。
🇹🇼 台語模式
選到臺灣台語／Hokkien Pop／歌仔戲台語情境時，Style 固定加入 Taiwanese Hokkien；每個有人聲的歌詞段落固定加入 [Taiwanese Hokkien accent vocal]。純器樂段落不加，避免 Vocal / Instrumental 衝突。
資料標籤怎麼看？
✅ Established＝已有穩定使用的曲風／類型；🎬 Scene＝場景或社群名稱；🌀 Microgenre＝微流派；🌍 Regional descriptor＝地區描述；🧩 Modifier / Practice＝輔助描述或實驗創作方法；🧪 Suno-tested＝創作者實測有效寫法；Guide-tested＝外部指南／社群經驗只作補缺與參考。兩者都不代表 Suno 官方固定 Tag。

提醒：Prompt 能提高方向一致性，但不能保證每次生成百分之百遵從。相同設定多生成幾個版本仍是 AI 音樂創作的重要流程。
